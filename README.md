# AI4Food Repository #
Please cite "AI for food: accelerating and democratizing discovery and innovation" (https://doi.org/10.1038/s41538-025-00441-8) when using this repository 
in addition to the relevent papers for each dataset.

## AI4Burgers ##
"Generative Artificial Intelligence creates delicious, sustainable, and nutritious burgers" (https://doi.org/10.48550/arXiv.2602.03092)

## AI4Meatballs ##
"The Meatball Matchup: Plant vs. Animal Proteins on Campus" (https://doi.org/10.64898/2026.03.05.709981)

## AI4Shrimp
Deidentified paired sensory, CATA, and texture-profile data with table-only
analysis code.

## AI4BurgerExperiment
Deidentified primary-experiment consumer sensory and texture-profile data with
table-only analysis code. Participant-level subgroup data are excluded.

## AI4Cheese
Deidentified paired sensory, texture-profile, and frequency-sweep rheology data
with table-only analysis code.
